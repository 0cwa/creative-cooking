# Optional mailbox

`openMailbox` opens a single-process SQLite mailbox with FULL synchronous commits. The operator provisions random mailbox IDs and distinct 256-bit read and append capabilities via its local API; store and distribute those secrets securely outside this module. A mailbox has a byte quota and an absolute expiry. Expiry blocks access and does not delete data. There is no member delete or compaction endpoint. Operators must publish retention and backup terms; physical pruning is deliberately not implemented. Use TLS except on loopback for development. This module does not deploy or start a public service.

Supply `hashProvider` using the same BLAKE2b-256 implementation as the candidate codec and configure the relay Ed25519 signing key. The relay identity is the SHA-256 hash of its DER SubjectPublicKeyInfo. Each signed receipt binds that identity, protocol domain, mailbox, object ID, size, PUT path and configured expiry.

The relay stores opaque candidate ciphertext and signs a receipt after the transaction commits. Its Ed25519 public key must be pinned through an authenticated channel. The client requires a verifier and checks every claim against the upload before returning a receipt; it never records a peer receipt. A receipt attests only the relay's claim of storage, not delivery, application, authority or future availability. Candidate object IDs and receipt wire encoding are provisional until the shared contract owner freezes them. A production operator must configure persistence on a filesystem supporting SQLite durable sync, secure the database and signing key, terminate TLS, and measure limits.

The client returns verified relay receipts to its caller; integration must persist them as `destination: relay, state: stored` only after verification. The caller must stage fetched bytes and cursor using the local atomic inbox contract, then independently authenticate and apply the object. This module does not advance application cursors or create peer receipts. Candidate crypto and wire compatibility remain subject to the shared C1 freeze.

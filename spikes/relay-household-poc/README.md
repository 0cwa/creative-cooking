# Relay household experiment

Run `npm ci --offline && npm test` in this directory. The fixed schedule has no random sampling; the seed labels its inputs. The test executes it twice and compares byte-identical summaries. Loro 1.17.1 merges structured recipe maps and independent purchase IDs, tolerates duplicate/reordered updates and reopens a disk snapshot. Same-field intentions are reported alongside the winner; convergence does not preserve both as current values.

Recovery and trust are small pure event-driven models. Recovery counts distinct available holders, including correlated loss and withholding; device copies do not create extra guardians. A code or shares can unwrap only under modeled conditions; a separate assumed adult confirmation is required for confirmed recovery. Trust fixes the electorate at the parent, counts assumed signatures, deduplicates semantically identical proposals, and derives device heads and quarantine from delivery. It compares unilateral and fixed 2-of-4 rules, not an all-reachable quorum. Different pairs can authorize conflicting successors; relay order selects no authority. Explicit copy and accepted invitation create a new modeled epoch while preserving provenance and the original inbox.

Keys, signatures, consent, and confidentiality are assumptions, not implemented cryptography or a security proof. Future data-epoch and device keys must be independently random; a recovery secret only wraps a key catalog, never derives future keys or device identity. Guardian recovery concerns household continuity rather than personal data; these remain product choices. Guardian changes require fresh wrapping keys, shares and credentials, not rewrapping an old credential. Disk reload demonstrates serialized inbox/outbox retention, not atomic transactions or crash consistency. No network, production services, or existing-data migration is modeled.

V5 compares device and adult votes when Ana owns two of three devices, then takes Ben's explicit checkpoint choice and selected benign semantic operations as inputs. A separate clean Loro document is reconstructed; excluded history remains in the model export. This does not establish which device is honest or prove selective removal of causal CRDT operations. The personal guardian example explicitly exposes the package to the threshold when enabled.

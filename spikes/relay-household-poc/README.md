# Relay household experiment

Run `npm ci --offline && npm test` in this directory. The fixed schedule has no random sampling; the seed labels its inputs. The test executes it twice and compares byte-identical summaries. Loro 1.17.1 actually merges structured recipe maps and independent purchase IDs, tolerates duplicate/reordered updates and reopens a snapshot. Same-field intentions are reported alongside the winner; convergence does not preserve both as current values.

The remaining results are deliberately scripted protocol-state examples, not a network simulation, governance recommendation, cryptography implementation, or probability estimate. Logical times and minutes are illustrative assumptions. Recovery assumes Dee retained her printed secret; null lockout means no recovery within the modeled window. Guardians are three independent people and only key recovery is thresholded. The scenario treats each branch's approvals as given, rather than simulating signatures or voting. All adults are equal; device replacement is not a membership change. The JSON round-trip checks model preservation only, not disk durability. New epoch confidentiality is assumed, not tested. No existing data is migrated.

# Local-first research archive

These are the write-ups from the October 2026 sync spikes and the research that came before them. The project later chose Loro with an optional encrypted relay. See `docs/plans/LORO-IMPLEMENTATION-DECISIONS.md` on the Loro branch, and PR #53. The PowerSync implementation from PR #52 is shelved on the `archive/powersync-2026-11-15` branch.

Each spike's code was not merged. It is kept on the git tag listed below, and its PR is closed. Relative links to scripts, workflows or experiment code in these documents resolve only when you check out that tag (`git checkout archive/spike/<name>`).

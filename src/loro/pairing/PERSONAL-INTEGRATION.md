# Candidate own-adult device admission

This patch depends on the already integrated `candidate-v2.mjs`, `durable-session.mjs` and `key-package.mjs`. It keeps the original `candidate.mjs` intact. `personalAdmissionBytes` binds the pinned parent snapshot, sponsor, one existing owner, recipient, the recipient public key bundles, peer ID, transcript hash and guard. New-device key references are required to equal the lowercase hexadecimal public keys; the application's key resolver must support this convention.

`openPersonalPairing` requires independent local session evidence and pinned personal authority. Its sponsor `release(operationId, localKeys, keyOperation, keyIdentity, peerId)` returns `{release, admission}`. The authenticated envelope must be transported intact to the recipient. `install(envelope, recipient, master, masterId, keyRef)` checks the same evidence and commits the wrapped key, signed receipt and signed authority successor together. Release and installation are separate local transactions. Each transaction compares durable authority and commits its corresponding records together. Exact retries require the saved successor still to be current; changed authority requires a new ceremony.

`TransactionalStorage.commitPersonalAdmissionRelease` and `RecipientRecords.installPersonalAdmissionAndReceipt` are structural transaction seams, not signature verifiers: only call them after the personal admission verifier. Both share the existing `pairing-guard` namespace with projection publication. The patch leaves projection guard and source revision/owner checks intact. Household admission remains unavailable without its separate authority verifier.

Run the Node tests using `agent-heavy -- node --test src/loro/authority/personal-admission.test.mjs src/loro/pairing/personal-atomic.test.mjs`. For IndexedDB/WebCrypto, run `agent-heavy -- node src/loro/pairing/personal-browser-server.cjs` and evaluate `(await import('/browser-personal.mjs')).run()` in an isolated browser at localhost:19375. The fixture uses separate databases in one browser process and deletes them. It does not prove isolated browser providers, native secure master, Hermes, ARM or iOS.
